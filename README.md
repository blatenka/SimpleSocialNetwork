\# Social Network



A simple social network application built with Java, Spring Boot, and WebSocket.



\## Goals



\- Improve Java programming skills

\- Improve Spring Boot development skills

\- Practice REST API development

\- Learn WebSocket and real-time communication

\- Practice database design and JPA/Hibernate

\- Learn authentication and authorization

\- Apply software engineering practices



\## Tech Stack



\- Java

\- Spring Boot

\- Spring Data JPA

\- Spring Security

\- WebSocket

\- MySQL

\- MongoDB
